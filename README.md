# bolsa-futuro-digital

Aulas e exemplos criados para o curso de Frontend do programa Bolsa Futuro Digital do governo federal. O objetivo das aulas é ensinar desenvolvimento de páginas web utilizando HTML5, CSS3 e JavaScript. As aulas e exemplos serão adicionados ao decorrer do semestre.

O material foi pensado para quem tem pouco ou nenhum conhecimento de programação.

Muito do que está disponível aqui foi inspirado nas aulas do professor Gustavo Guanabara do canal Curso em Vídeo, tomei muitos de seus exemplos emprestados e devolvo os devidos créditos.
